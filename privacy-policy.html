《Everhorde: Endless Swarm》隐私政策

生效日期：2026年9月17日

Onyx Colt Forge（以下简称“我们”）系移动应用程序《Everhorde: Endless Swarm》（以下简称“本游戏”，应用包名 com.OnyxColtForge.EverhordeEndlessSwarm）的运营者。我们非常重视保护用户（以下简称“您”）的个人信息和隐私。您在使用本游戏时，我们会收集、使用、保存、共享相关个人信息。我们承诺严格按照本隐私政策处理您的个人信息。

在您使用本游戏前，请认真阅读本隐私政策。您点击“同意”并使用本游戏，即表示您同意我们按照本政策处理您的个人信息。本政策仅适用于我们通过本游戏向您提供服务所收集的信息，不适用于第三方独立向您提供服务所收集的信息。

本隐私政策将帮助您了解以下内容：一、我们如何收集和使用您的个人信息；二、设备权限调用情况；三、我们如何保存您的个人信息；四、Cookies 和同类技术；五、我们如何共享、转让、公开披露您的个人信息；六、第三方 SDK 如何获得您的个人信息；七、我们如何保护您的个人信息；八、您如何管理您的个人信息；九、我们如何处理未成年人的个人信息；十、本隐私政策如何更新；十一、如何联系我们。

一、我们如何收集和使用您的个人信息

（一）完成登录。本游戏不提供独立的手机号注册。您通过 TapTap 账号登录。经您授权后，我们可能处理 TapTap 账号的公开资料（如昵称、头像）以及用于识别登录状态的标识。如您不完成登录，将无法使用本游戏的联网登录服务。

（二）游戏服务。当您使用游戏服务时，为保障运行、适配设备并保存进度，本游戏会在设备本地保存角色进度、设置等存档；TapSDK 与 Unity 引擎可能处理设备型号、系统版本、CPU 与内存信息、网络类型、Android ID 等。如您不提供上述为实现服务所必需的信息，可能无法正常使用本游戏。

（三）实名认证。为履行网络游戏实名与防沉迷法定义务，本游戏接入 TapTap 合规认证。实名身份信息由 TapTap 按国家要求核验，本游戏不自行存储您的身份证号，仅接收是否可进入游戏及适龄相关结果。如您不完成实名认证，将无法登录或使用本游戏。

（四）保障网络和服务安全。为完成登录、实名认证及必要网络通信，相关 SDK 可能处理设备识别信息、网络类型等。本游戏当前不提供云存档，也不会把本地存档上传到我们的服务器。

（五）我们不会开展的处理。本游戏无应用内购买，未接入广告联盟或广告 SDK，不会为广告投放、个性化推荐广告之目的收集或共享您的个人信息。我们不会出售您的个人信息。

（六）依法无需同意的情形。根据法律法规及国家标准，与履行法定义务、国家安全、公共安全、刑事司法、维护您或他人重大合法权益、维护服务安全稳定运行等情形相关时，我们可能依法处理相关信息。

二、设备权限调用情况

我们不会在您同意本政策之前初始化 TapSDK。我们不会默认开启与游戏无关的敏感权限。本游戏主要使用网络访问权限，用于 TapTap 登录、合规认证及必要服务通信。Unity 引擎可能使用加速度传感器用于画面方向适配，相关处理在设备本地进行。

如系统弹出权限申请，将说明用途。您可在设备设置中关闭权限；关闭后，依赖该权限的功能可能无法使用。

三、我们如何保存您的个人信息

本地存档仅保存在您的设备上。与 TapTap 登录和合规认证相关的信息，由易玩（上海）网络科技有限公司按其隐私政策处理。我们不会额外建立用户个人信息数据库。

我们将在实现本政策所述目的所必需及法律法规要求的期限内保存相关信息，期限届满后删除或匿名化处理。我们在中国境内运营过程中收集和产生的个人信息原则上保存在中国境内。

四、Cookies 和同类技术

本游戏不是网站服务，不使用网页 Cookies 进行广告推荐。我们可能在设备本地保存游戏进度与设置，其目的仅为继续游戏，不用于向第三方投放广告。

五、我们如何共享、转让、公开披露您的个人信息

除为实现登录与防沉迷而向 TapTap（易玩（上海）网络科技有限公司）提供必要信息，或法律法规、有权机关依法要求外，我们不会与第三方共享您的个人信息。

我们不会转让您的个人信息，但涉及合并、收购、资产转让等情形时，我们将依法告知并要求继受方继续受本政策约束，否则将重新征得您的同意。

除非法律明确规定，我们不会公开披露您的个人信息。

六、第三方 SDK 如何获得您的个人信息

为提供登录、防沉迷及游戏运行能力，本游戏接入以下 SDK。具体收集和使用情况以该 SDK 运营方的隐私政策为准。

1. 名称：TapSDK（含 TapTap 登录、合规认证）。运营方：易玩（上海）网络科技有限公司。使用目的：账号登录、实名与防沉迷、保障服务稳定。可能处理的信息：网络状态、系统版本、设备型号、CPU 信息、设备内存信息、网络类型、Android ID；经您授权的 TapTap 账号公开资料及登录标识；防沉迷认证结果。隐私政策：https://developer.taptap.cn/docs/sdk/start/agreement/

2. 名称：Unity 引擎。运营方：Unity Technologies。使用目的：游戏运行、设备与画面适配。可能处理的信息：设备型号、系统版本、传感器数据、Android ID 等引擎运行所必需的信息。隐私政策：https://unity.com/cn/legal/privacy-policy

七、我们如何保护您的个人信息

我们采取合理可行的安全措施保护您的信息，例如仅在必要范围处理信息、控制访问等。互联网环境并非百分之百安全。如发生个人信息安全事件，我们将按法律法规要求及时处置，并在难以逐一告知时通过合理方式公告。

八、您如何管理您的个人信息

您可以查阅本政策。您可通过卸载本游戏删除本地存档，并在 TapTap 侧管理账号授权。本游戏无独立游戏账号体系；如需更正、删除与本游戏相关的信息，或撤回同意，请通过本游戏在 TapTap 页面公示的开发者联系方式与我们联系。我们将在核实身份后依法处理。

您撤回同意后，我们将无法继续提供对应服务，但不影响此前基于您的授权已开展的处理。

九、我们如何处理未成年人的个人信息

本游戏接入国家要求的实名认证与防沉迷服务。收集、使用未满十四周岁未成年人的个人信息，需由监护人授权同意。未成年人使用本游戏须由其监护人同意本政策，并遵守防沉迷时段与时长规定。监护人如有疑问，请通过本政策载明的方式联系我们。

十、本隐私政策如何更新

我们可能适时修订本政策，并在本页面发布更新。对重大变更，我们将通过游戏内弹窗等方式再次征得您的同意。未经您明确同意，我们不会削减您按照本政策所应享有的权利。
